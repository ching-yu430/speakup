# 🗣️ Speak Up - 你的專屬語感培養與實戰英文教練

**Speak Up** 是一個輕量級、功能強大的單頁式網頁應用程式 (SPA)，專為台灣學習者設計的英文口說與聽力練習工具。無需安裝任何 App 或依賴資料庫，所有的學習數據皆安全地儲存在你的瀏覽器本地端，並結合了強大的 **Google Gemini API** 來提供無限延伸的情境與即時新聞對話練習。

---

## ✨ 核心特色功能

### 1. 📚 系統題庫 (System Vocabulary Bank)
內建豐富的單字、片語及實用句型，並透過「階梯式學習」幫助你循序漸進地掌握：
- **階段學習**：從單字 (Word) 基礎開始，進階到片語 (Phrase) 與完整句子 (Sentence)。
- **盲測模式**：可隱藏中文翻譯，強迫大腦直接將英文與情境連結，不再依賴死記硬背。

### 2. ✨ AI 情境擴充 (AI Scenario Generation)
覺得系統題庫不夠用？只要輸入你想練習的「特定情境」（例如：去健身房詢問會員方案、在機場行李遺失），系統會即時呼叫 Gemini API，為你客製化生成專屬的單字、片語及對話句子，讓你的英文學習完全貼合實際生活需求。

### 3. 📰 每日新聞時事 (BBC News Learning)
系統會自動抓取最新的 BBC News 國際頭條 RSS，並透過 AI 即時翻譯與整理，為每則新聞提煉出「核心單字」及「實戰對話情境」，讓你每天都能用最道地的英文聊世界大事。

### 4. 💬 實戰對話 (Roleplay Conversation)
提供模擬真實對話的互動介面。無論是點餐、面試還是閒聊，你可以使用內建的「語音辨識 (Speech-to-Text)」功能對著麥克風開口說，AI 會扮演對手與你進行全英文對話演練，並給予你回饋。

### 5. 🏺 語感花室 (Streak Garden)
視覺化的成就系統！透過每天持續登入練習，你的「語感花室」會長出專屬於你的連勝盆栽。結合柔和的大地色系漸層背景，讓你在無壓力的狀態下，每天看著自己的努力開花結果。

### 6. 🔁 隨機抽考與複習 (Spaced Repetition)
自動從你過去「已完成」的題目中隨機抽取（包含系統題庫與你生成的 AI 情境），讓你在毫無預期壓力的情況下，隨機溫故知新，加深大腦記憶。

## 🛠️ 技術架構

本專案秉持「極簡而強大」的原則，完全無需後端伺服器：
- **前端核心**：純 HTML5 + CSS3 (自訂設計系統) + Vanilla JavaScript。
- **資料儲存**：高度依賴瀏覽器的 `localStorage`，所有使用者的練習進度、連勝紀錄、AI 生成單字、收藏清單皆儲存於本地端。並具備完整的防崩潰保護 (`try...catch` 封裝)，確保在 iOS Safari 的隱私模式下也能穩定運作。
- **AI 驅動**：透過 fetch 直接與 Google Gemini (Generative Language API) 對接。
- **語音系統**：深度整合瀏覽器原生的 `Web Speech API` (包含 `SpeechSynthesisUtterance` 與 `webkitSpeechRecognition`)，支援跨平台（包含 iOS / Safari）的語音朗讀與麥克風收音。

## 🚀 如何開始使用 (Getting Started)

1. **Clone 專案**
   ```bash
   git clone https://github.com/yourusername/speak-up.git
   cd speak-up
   ```

2. **準備你的 Gemini API Key**
   - 前往 [Google AI Studio](https://aistudio.google.com/) 申請一組免費的 API Key。

3. **啟動專案**
   - 因為本專案是純靜態網頁，你只需要使用任何網頁瀏覽器（推薦使用 Chrome 或 Safari）直接打開 `index.html` 即可運行！
   - *（如果是透過手機使用，建議將網頁「加入主畫面」，獲得最完美的無邊框全螢幕沉浸體驗。）*

4. **輸入 API Key**
   - 點擊網頁左上角的 ⚙️ (設定) 按鈕。
   - 在輸入框中貼上你的 Gemini API Key 並儲存。
   - 恭喜！你已經解鎖了所有 AI 情境生成與實戰對話功能！

## 💡 使用小提示 (Tips)

- **自動發音**：點擊任何單字卡片右側的 🔊 圖示，系統會為你示範標準的英文發音。
- **我的收藏**：在練習過程中遇到不熟悉的單字，隨時點擊 ⭐ 收藏，並在「收藏」分頁中集中特訓。
- **保護你的 API Key**：本專案的 API Key 僅會儲存在你個人的瀏覽器本地端，不會回傳至任何第三方伺服器，請安心使用。
