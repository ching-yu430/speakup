📖 快速上手指南

1. 📚 系統題庫與自然發音
內建 15 大主題、超過 700 筆對話與單字題庫。系統會自動顯示「自然發音拼寫」與音標，並支援自由切換美式/英式口音，跟著聲音唸就對了！

2. 🧠 弱點單字本與間隔複習
系統會依照你每次唸的分數自動排定「下次該複習的時間」(講得不好會提早重考,講得好會拉長間隔)。點選「隨機抽考」時,真正到期、講得不順的題目會優先出現;點選「弱點單字」則能直接看到目前所有還沒克服的題目清單,一鍵跳過去複習。

3. 🏺 語感花室與成就分享
每天登入練習就能為你的專屬盆栽澆水，連續學習還會長出不同品種的花朵與特效。你還可以一鍵將「語感花室」或「本週學習週報」生成精美的專屬小卡下載，與朋友分享你的學習成就！

4. ✨ 解鎖 AI 情境與對話教練
前往 Google AI Studio 免費申請 Gemini API Key 並在設定中貼上，即可解鎖「自訂情境生成」、「BBC 新聞每日對話」與「麥克風實戰角色扮演 (Roleplay)」的強大功能！

5. 🔗 GitHub Gist 雲端同步
在設定裡貼上自己的 GitHub Token,就能把學習進度上傳到一個只有你自己看得到的私人 Gist,在另一台裝置貼上同一組 Token 後按「下載雲端還原」即可同步過去,不用再手動傳檔案。

6. 🔔 每日練習提醒
在設定裡開啟提醒並選好時間,只要當天還沒開口練習,系統就會跳出通知提醒你。提醒需要瀏覽器分頁或已安裝的 App 留在背景執行才會跳出來,完全關閉瀏覽器是收不到的——這是純前端網站(沒有後端伺服器)能做到的極限。

7. 🔒 隱私安全與跨平台支援
所有的學習資料、連勝紀錄和 API Key 都只會安全地儲存於你的瀏覽器中。完美支援 Android、Chrome 以及 iOS 系統的語音引擎。
