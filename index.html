📖 快速上手指南

1. 如何使用 Gemini API Key？
前往 Google AI Studio 免費申請 API Key，貼入「✨ AI 情境」選單中的欄位，即可無限生成專屬的單字與情境對話。

2. 手動新增與自訂單字
網頁最下方的「想加自己的內容?」區塊，輸入英文後，系統會自動查詢音標，如果有 API Key 還會自動翻譯。

3. 盲測挑戰與設定
在主畫面上方開啟「👁️ 盲測」，可以隱藏英文單字訓練聽力與口說。下方還可自由切換美式/英式口音，與調整慢速播放速度。

4. 隱私安全
所有的學習資料、API Key 都只會儲存於你的瀏覽器，並不會上傳到任何伺服器。
沒有標準答案,只有講出口的你。
